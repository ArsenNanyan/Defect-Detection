# NEU-DET — Data Audit & Split Report (Step 1)

Generated by `scripts/audit_data.py` + `scripts/make_splits.py` (seed 42).
Reproduce:

```bash
python scripts/repair_raw.py  --raw data/raw/neu_det
python scripts/audit_data.py  --raw data/raw/neu_det --out artifacts/reports
python scripts/make_splits.py --raw data/raw/neu_det --out data/splits --seed 42
```

## 1. Dataset as shipped

- **1,800 images**, all **200×200**, grayscale steel textures (XML declares `depth=1`).
- 6 classes, **300 images each** (balanced): crazing, inclusion, patches,
  pitted_surface, rolled-in_scale, scratches.
- Pascal VOC XML boxes: **0–9 boxes/image, mean 2.33**. Class folder = authoritative
  image-level label.

## 3. Classification label protocol (single-label, documented)

- **Single-label = class subfolder** (authoritative; NEU-DET is organized this way and
  folder/XML never disagree).
- The 123 multi-class images are **kept** (not excluded) and flagged with
  `multi_class=True` in the manifests, enabling an **optional multi-label experiment**
  later without changing the split.
- **Detection preserves all boxes and all classes** regardless of the single label.

## 4. Immutable split (one split reused by every classification & detection experiment)

- Pooled train+validation → **stratified 70/15/15 by class, seed 42**, groups kept whole.
- `group_id` = connected components over dhash Hamming distance ≤ 4.
- Hard asserts: **no `sha256` and no `group_id` spans more than one split.**

| Split | Images |
|---|---|
| train | 1,252 |
| val | 270 |
| test | 278 |

Per-class counts are balanced across splits (see `data/splits/split_meta.json`).
**The test split is frozen** — used once, at the end, never for tuning or checkpoint selection.

Manifests (committed): `data/splits/{train,val,test}.csv`, `all.csv`, `split_meta.json`.
Columns: `image_path, annotation_path, label, class_names, multi_class, group_id, sha256, split`.
